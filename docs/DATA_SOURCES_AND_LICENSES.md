# ZIZIPHUS JUJUBA: Источники данных и лицензии (Data Sources & Licenses)

## 1. Первоисточники радиожурналов
1. **Priyom.org (Shortwave Radio Monitoring Project):**
   * Ресурс: [https://priyom.org/military-stations/russia/the-buzzer](https://priyom.org/military-stations/russia/the-buzzer)
   * Тип данных: Открытые первичные журналы радиоперехватов коротковолновых станций.
   * Статус: Общедоступный исследовательский архив (Public Domain / Open Research).
   
2. **UVB-76 Structured Signal Analysis Repository:**
   * Репозиторий: [https://github.com/Leerrooy95/UVB-76-Structured-Signal-Analysis](https://github.com/Leerrooy95/UVB-76-Structured-Signal-Analysis)
   * Назначение: Первичный сбор текстовых логов за 2010–2022 гг.
   * Лицензия исходных текстов: Open Source / MIT / Academic Citation.
