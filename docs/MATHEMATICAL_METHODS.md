# ZIZIPHUS JUJUBA: Документация по математическим и статистическим методам (Mathematical Methods)

В исследовательской системе ZIZIPHUS JUJUBA применяются методы прикладной математической статистики, теории точечных процессов, анализа графов и множественного тестирования гипотез.

---

## 1. Анализ точечных процессов и проверка пуассоновской гипотезы

### 1.1. Коэффициент вариации межпосылочных интервалов
Для последовательности временных интервалов между радиограммами $\Delta t_1, \Delta t_2, \dots, \Delta t_n$:
$$CV = \frac{\sigma_{\Delta t}}{\mu_{\Delta t}}$$
* Для пуассоновского потока (экспоненциальное распределение интервалов без памяти): $CV \approx 1.0$.
* Для УВБ-76: $CV = 2.41 > 1.2$, что отвергает гипотезу независимости событий.

### 1.2. Фактор Фано (Fano Factor / Dispersion Index)
Отношение дисперсии к среднему числу событий в фиксированных окнах:
$$D = \frac{\mathrm{Var}(X)}{\mathbb{E}[X]}$$
* Для процесса Пуассона: $D = 1.0$.
* Для УВБ-76: $D = 14.8 \gg 1.0$, что доказывает наличие сильной кластеризации (burstiness) и группировки сообщений в серии.

## 2. Модель роста лексикона (Закон Хипса)

Описывает зависимость объема уникального словаря $V$ от общего числа переданных радиограмм $N$:
$$V(N) = k \cdot N^\beta$$
Логарифмическая линеаризация для оценки методом наименьших квадратов (OLS):
$$\ln V(N) = \ln k + \beta \ln N$$
* Для естественного открытого языка: $\beta \approx 0.85 - 0.95$.
* Для УВБ-76 эмпирическая оценка: $\beta = 0.742$, $k = 2.14$.
* Сублинейность ($\beta < 1$) подтверждает, что кодовые слова выбираются из ограниченного служебного словаря объемом около 1 500 – 2 000 терминов.

---

## 3. Обнаружение аномалий: робастный Modified Z-Score (MAD)

Поскольку распределение ежедневного объема радиограмм содержит тяжелые хвосты и экстремальные выбросы, классическое стандартное отклонение искажается. Применяется робастная медианная модификация Иглевича — Хоглина:

$$\mathrm{MAD} = \mathrm{median}(|x_i - \mathrm{median}(X)|)$$
$$M_i = \frac{0.6745 \cdot (x_i - \mathrm{median}(X))}{\mathrm{MAD}}$$

Дни с $M_i \ge 3.0$ классифицируются как статистически аномальные всплески.

## 4. Коррекция на множественное тестирование гипотез (FDR и Bonferroni)

При одновременной проверке связи активности радиообмена с $m = 15$ историческими событиями возникает проблема множественных сравнений.

### 4.1. Поправка Бонферрони
Консервативный порог:
$$\alpha_{bonf} = \frac{\alpha}{m} = \frac{0.05}{15} \approx 0.00333$$

### 4.2. Метод контроля доли ложных открытий (Benjamini-Hochberg FDR)
1. Упорядочиваем эмпирические $p$-значения: $p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$.
2. Вычисляем скорректированные $q$-значения:
   $$q_{(i)} = \min \left( 1.0, \, p_{(i)} \cdot \frac{m}{i} \right)$$
3. Отвергаем нулевую гипотезу для тех событий, где $q_{(i)} \le 0.05$.

## 5. Топологический анализ графов (Network Metrics)

Для графа связей $G = (V, E)$:

### 5.1. Плотность графа (Density)
$$D = \frac{2 |E|}{|V|(|V| - 1)}$$

### 5.2. Транзитивность (Коэффициент кластеризации)
$$T = \frac{3 \times (\text{число замкнутых треугольников})}{(\text{число триад ребер})}$$

Позволяет отслеживать фазовые переходы от изолированных звездных структур (Эпоха 1) к плотно связанным сетевым кластерам (Эпоха 2).
