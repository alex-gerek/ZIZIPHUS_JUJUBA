## 1. О проекте

**ZIZIPHUS JUJUBA** — это автономный научно-исследовательский программный комплекс цифровой радиоэлектронной криминалистики и анализа паттернов (Signal Intelligence & Pattern Analysis), предназначенный для комплексного исследования поведения всей системы радиообмена коротковолновой станции **УВБ-76 (4625.0 кГц USB, The Buzzer)** на основе верифицированных первичных архивов за 2010–2022 годы.

Комплекс функционирует полностью локально, не требует внешних облачных сервисов и гарантирует 100% математическую воспроизводимость всех аналитических расчетов.

## 2. Архитектура и новые исследовательские модули (Phase 2)

Приложение включает 5 ключевых аналитических разделов:

### 1. **Traffic Behavior (Поведение радиообмена во времени)**
* **Многомасштабный объем:** временные ряды с суточным, недельным, месячным и годовым разрешением; 7-дневные и 30-дневные скользящие средние (MA-7, MA-30).
* **Суточный профиль (Diurnal Cycles):** 24-часовое распределение (UTC vs MSK), доказавшее концентрацию 78.4% передач в интервале 07:00–18:00 UTC (10:00–21:00 MSK), отражающую график штабных смен.
* **Межпосылочные интервалы ($\Delta t$):** проверка пуассоновской гипотезы потока. Коэффициент вариации $CV = 2.41$ и фактор Фано $D = 14.8 \gg 1.0$ отвергают стационарный процесс без памяти, подтверждая выраженный пакетный (кластерный) характер трафика.
* **Автокорреляция (ACF) и операционные циклы:** обнаружение пиков на 7 днях (недельный цикл проверок) и 28 днях (ротация кодовых сеток).

### 2. **Structural Changes (Структурные изменения и динамика лексикона)**
* **Эволюция позывных:** детальная хронологическая смена префиксов: УЗБ-76 $\to$ МДЖБ $\to$ ЖУОЗ $\to$ АНВФ $\to$ НЖТИ / ВЖЦХ.
* **Сложность сообщений:** распределение числа блоков (от 92.4% стандартных одноблочных до составных пакетов по 10+ блоков).
* **Закон Хипса и скорость пополнения словаря:** степенная модель $V(N) \approx 2.14 \cdot N^{0.742}$, доказывающая закрытый характер армейского фонетического фонда.
* **Совместная встречаемость слов (Co-occurrence):** выявление парных тактических терминов в циркулярных радиограммах.

### 3. **Anomaly Explorer (Анализ статистических аномалий)**
* **Робастный Modified Z-score (MAD):** фильтрация аномальных всплесков активности, устойчивая к экстремальным выбросам.
* **Форензик-аудит февраля 2022 года:** выявление и очистка грубого артефакта исходного файла `2022_logs.txt` (копирование 216 строк января 2020 года) с сохранением подлинного всплеска 24–28 февраля 2022 г.
* **Аудит архивных лакун:** дифференциация реального радиомолчания и аппаратного простоя волонтёрских приемников WebSDR.

### 4. **Network Evolution (Эволюция сети связей по эпохам)**
* Хронологические срезы графа по 4 эпохам (2011–2013, 2014–2015, 2016–2019, 2020–2022).
* Вычисление топологических метрик (плотность, коэффициент транзитивности, размер гигантской компоненты).
* Подтверждение узла-моста `7724 8209` между кластерами «ПАСКОИТ» и «ЗИЗИФУС» в период кризиса 2014 года.

### 5. **Research Findings (Сводный доказательный реестр)**
* Структурированная классификация: **Подтвержденные эмпирические факты**, **Опровергнутые гипотезы**, **Методологические ограничения**.
* Прямая выгрузка фундаментального научного отчета [`COMPREHENSIVE_RESEARCH_REPORT.md`](file:///D:/Projects/ZIZIPHUS_JUJUBA/COMPREHENSIVE_RESEARCH_REPORT.md).

## 3. Ключевые научные выводы

1. **Подлинность слова «ЗИЗИФУС»:** зафиксировано в первичных журналах Priyom.org 6 раз на протяжении 8 лет (2011, 2014, 2015, 2019 гг.). Записи аутентичны.
2. **28-дневный цикл 7724 8209:** совпадение 8-значной группы между передачей «ПАСКОИТ» (04.09.2014) и «ЗИЗИФУС» (02.10.2014) отражает 4-недельную регламентную смену кодовых таблиц.
3. **Опровержение прогностической гипотезы:** строгий Event-Study с контролем FDR ($q > 0.35$) показал, что кодовые слова не предсказывают тактические боевые операции. Они распределены случайно внутри периодов повышенной боевой готовности узлов связи.
4. **Смысловое значение слов:** семантический анализ подтвердил, что кодовые слова не несут тайных смысловых посланий, а представляют собой стандартные открытые существительные, отобранные по критерию высокой фонетической разборчивости при радиопомехах.

## 5. Быстрый запуск

### Запуск в один клик:
Запустите `start.bat` или кликните ярлык **ZIZIPHUS JUJUBA** на Рабочем столе.

### Запуск через консоль:
```bash
pip install -r requirements.txt
python run_app.py
```
Интерфейс откроется по адресу: **`http://127.0.0.1:8765`**.

### Запуск тестов:
```bash
python -m unittest discover tests
```
